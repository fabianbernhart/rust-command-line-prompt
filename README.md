# Rust Command Line Prompt

> An early Rust learning project.

## About

This repository contains some of my first experiments with [Rust](https://www.rust-lang.org/).

The goal was to get familiar with the language by rewriting existing command-line utilities. It was a small learning project inspired by the Rust practice projects listed by Zero To Mastery.

I also experimented with the [`colored`](https://github.com/colored-rs/colored) crate to add colored terminal output.

## Implemented commands

- [x] `echo` – Repeats input
- [x] `cat` – Concatenates and displays files
- [x] `ls` – Lists directory contents
- [ ] `find` – Locates files or directories
- [ ] `grep` – Searches for matching text in files

## Dependencies

- [`colored`](https://crates.io/crates/colored) – Terminal text coloring

## Status

**Archived.**

This project served its purpose as an introduction to Rust. Development has stopped, and the repository is preserved for reference.
